适合谁

WHO IT IS FOR

有人负责、要看结果的地方，都用得上

Anywhere work has an owner and results matter

公司项目管理

Company project management

需求、排期、阻塞在同一本账上，不开周会也知道进度，Agent 干的活也有人负责。

Requirements, schedules and blockers in one ledger. Know the status without a weekly meeting, and every Agent’s work has an owner.

HR · 绩效考核

HR · Performance reviews

谁负责什么、是否按期、验收结论和退回原因都留痕，评估有事实可依，不靠印象。

Who owned what, whether it was on time, acceptance results and reasons for rework are all on record. Reviews rest on facts, not impressions.

高校导师 · 科研团队

Advisors · Research groups

导师定课题和阶段标准，学生带着 Agent 推进；进展、卡点、成果一目了然，组会只谈问题。

The advisor sets topics and milestones; students push forward with their Agents. Progress, blockers and results are visible, so group meetings focus on problems.

个人创业 · 多 Agent

Solo founders · Many Agents

一个人开着好几个 Agent 跑多条线：一本账管住所有进度，你只做判断和签字。

One person, several Agents, many threads at once. One ledger keeps every thread in view; you only decide and sign.

接入 MCP

CONNECT OVER MCP

用你已经在用的 Agent，填一个地址

Use the Agent you already have. Add one address.

Claude

桌面应用、claude.ai、手机通用。设置 → 连接器 → 添加自定义连接器：

Desktop app, claude.ai and mobile. Settings → Connectors → Add custom connector:

https://pmm.aifor-u.com/mcp

高级设置里的客户端 ID 填 pmm-mcp-claude，点“连接”，浏览器登录一次。团队版由管理员给全组织加一次。

Under advanced settings set client ID pmm-mcp-claude, click Connect and sign in once. On Team plans an admin adds it for everyone.

Claude Code

终端里一条命令，第一次用时浏览器登录：

One command; sign in in the browser on first use:

claude mcp add --transport http pmm https://pmm.aifor-u.com/mcp

Codex

添加后登录一次：

Add it, then sign in once:

codex mcp add pmm --url https://pmm.aifor-u.com/mcp codex mcp login pmm

Kimi

桌面版或 Kimi Code。把下面这句话发给 Kimi，它会自己加好，第一次用时浏览器登录：

Desktop app or Kimi Code. Send Kimi this line; it adds PMM itself, and you sign in in the browser on first use:

把 https://pmm.aifor-u.com/mcp 加成 MCP 服务器 pmm，用 OAuth 登录

Kimi Code 也可以自己运行：

Or run it yourself in Kimi Code:

kimi mcp add --transport http --auth oauth pmm https://pmm.aifor-u.com/mcp kimi mcp auth pmm

DeepSeek Harness

它只支持本机进程，把这段话交给它自己执行，第一次用时浏览器登录：

It runs MCP servers as local processes only. Hand it this and let it do the work; you sign in in the browser on first use:

帮我接入 PMM：下载 https://pmm.aifor-u.com/downloads/pmm-agent.mjs 到 ~/.pmm-agent/；在当前档的 cordis.patch.yml 末尾加一个 - insert: 块（新组件必须放在 insert 里，写在顶层会被忽略），块里一条 @deepseek-ai/dsh-mcp-client，id 为 mcp-pmm，serverName 为 pmm，transport 为 stdio，command 为 node 的绝对路径，args 为 [pmm-agent.mjs 的绝对路径, "mcp", "--url", "https://pmm.aifor-u.com"]；然后调 pmm_whoami，按提示让我登录
Connect me to PMM: download https://pmm.aifor-u.com/downloads/pmm-agent.mjs into ~/.pmm-agent/; append a - insert: block to this profile's cordis.patch.yml (new plugins must go inside insert; a top-level entry is ignored) holding one @deepseek-ai/dsh-mcp-client entry with id mcp-pmm, serverName pmm, transport stdio, command the absolute path of node, args [the absolute path of pmm-agent.mjs, "mcp", "--url", "https://pmm.aifor-u.com"]; then call pmm_whoami and have me sign in when it asks

Claude Code 用国产模型

Claude Code on these models

DeepSeek、智谱 GLM、Kimi、通义千问都有 Anthropic 兼容接口。把 Claude Code 的模型指过去，PMM 照样一条命令：

DeepSeek, Zhipu GLM, Kimi and Qwen all offer Anthropic-compatible endpoints. Point Claude Code at one, and PMM is still one command:

export ANTHROPIC_BASE_URL=https://api.deepseek.com/anthropic export ANTHROPIC_AUTH_TOKEN=<your key> claude mcp add --transport http pmm https://pmm.aifor-u.com/mcp

地址以各家文档为准，例如智谱 https://open.bigmodel.cn/api/anthropic、Kimi https://api.moonshot.cn/anthropic。

Check each provider's docs for its address, e.g. Zhipu https://open.bigmodel.cn/api/anthropic, Kimi https://api.moonshot.cn/anthropic.

Claude、Claude Code、Codex、Kimi 不装软件、不下载文件；DeepSeek Harness 由它自己下载一个本机小程序。试点账号开通后即可登录；Agent 以你的身份读写，看得到的只是你在网页上能看的，令牌不进入 Agent 的对话和配置文件。

Claude, Claude Code, Codex and Kimi need nothing installed or downloaded; DeepSeek Harness fetches one small local program itself. Sign in once your pilot account is open. The Agent reads and writes as you, sees only what you can see on the web, and never holds your token in its chat or config.
