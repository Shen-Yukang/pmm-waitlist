Personal Agent 是什么

你的 Personal Agent，
就是你已经在用的 Claude Code 和 Codex。

我们不做通用的 Personal Agent。写代码、跑命令、读文件、做调研，是 Claude Code、Codex 和模型厂商的主场：模型、工作循环、本机环境，差距只会越拉越大。PMM 做的是让它们以你的身份接进团队的账本。

我们不做

再造一个什么都干的 Agent

  • 在服务器上写代码、跑命令
  • 文件转换、OCR、连代码仓库
  • 文档编辑、看板派活、群聊

这些交给更专业的工具：执行在 Claude Code、Codex，文档在 Notion、飞书文档，聊天在飞书、钉钉。

PMM 做的

给你的 Agent 开三个口子

  • 读整个项目：需求、任务、历史，只读你在网页上能读的
  • 交计划卡、回传调研报告：只是提案，你在网页上确认才生效
  • 回报进展和证据：提交成果可以，验收和确认只由人做

没有本地客户端？PMM 自带一个轻量 Agent 作备选，用你自己的模型 Key：讲清项目、回答问题、起草计划改动。

RSI · 持续学习，动态适应Coming soon

它会持续学习你的企业、团队和每个人，
越用越贴合。

账本里记下的不只是任务，还有企业的做事方式、团队在哪里卡住、哪些边界被越过、每个人的习惯和进步。PMM 持续从这些记录里学习，动态调整给每个人的提升建议和约束，并沉淀成团队自己的领域规范（DDD），让人和 Agent 用同一套说法对齐。

企业流程与规范团队合作与边界个人习惯与进步
  1. 01记录每个人的节奏、擅长的领域、做事习惯，从真实的提交、验收和退回里来，不靠自评。
  2. 02发现团队合作卡在哪：反复退回的需求、没人回答的提问、越过边界的改动，比如没验收就合并、改了别人负责的事。
  3. 03对齐把结论写进团队的领域规范：需求、任务、验收用同一套说法，人和 Agent 读同一份。
  4. 04约束与提升给每个人个性化的提升建议，给 Agent 和流程加上约束；规则可以配置，按团队自己的风格演进。
